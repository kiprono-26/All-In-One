# Servicely — Premium On-Demand Services Platform

Servicely is a modern on-demand service marketplace connecting clients with verified independent specialists across home maintenance, creative craft, kinetic wellness, automotive care, and business advisory.

---

## ✨ Features

- **Multi-Craft Marketplace**: Explore curated services across Home & Living, Creative & Digital, Wellness, Automotive Preservation, and Business Advisory.
- **Interactive Booking Configurator**:
  - 3-tier package comparison (`Essential`, `Standard`, `Master`).
  - Optional custom add-on enhancements with live pricing calculation.
  - Interactive 7-day scheduler with morning, afternoon, and evening time slots.
  - Transparent pricing with itemized fees and bonded insurance protection.
- **Customer Bookings Dashboard**:
  - Filter active, completed, and cancelled appointments.
  - Interactive appointment rescheduling and cancellations.
  - Printable tax receipts with invoice layouts.
  - Customer review submission with verified 5-star ratings.
- **Custom Quote Concierge**: Submit custom scopes with budget ranges and desired turnaround, matching with certified guild pros.
- **Provider Listing Portal**: Master specialists can list new crafts directly to the live marketplace catalog.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:3000` to view the application.

### Building for Production

```bash
npm run build
```

The production-ready output will be generated in the `dist/` directory.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Typography**: Outfit & Plus Jakarta Sans
- **Icons**: Lucide React
- **State & Storage**: Client-side reactive state with LocalStorage persistence
